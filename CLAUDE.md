# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Repository Overview

This is a documentation repository containing scripts and materials for AI-related talks and presentations. It is part of the **businessdatasolutions** GitHub organization.

There is no application code, build system, or test suite — the repo consists entirely of markdown documents in the `documentatie/` directory.

## Content & Language

All content is written in **Dutch**. When creating or editing documents, maintain Dutch as the working language unless explicitly asked otherwise.

## Current Content

- `documentatie/draaiboek-rotary-ai-talk.md` — A 60-minute interactive talk script ("De Spiegel — Van emotie naar urgentie") covering AI awareness for a Heideheeren audience. Structured in 5 segments with speaker notes and timing cues.

## Conventions

- Documents use markdown with emoji for visual structure (segment headers, speaker cues)
- Talk scripts follow a consistent format: timed segments, quoted speaker lines (blockquotes), and speaker notes at the end
- Versioning is noted at the bottom of each document (e.g., "versie 1.0 — The Solutions Architect Movement")
